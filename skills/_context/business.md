## Overview

**Immutable** is a web3 gaming platform building the operating system for game growth, identity, and monetisation.

It provides:
- Blockchain infrastructure (Immutable zkEVM / "Immutable Chain")
- Growth + data tooling (Audience)
- Distribution + engagement layer (Play)
- Identity + wallet system (Passport + Unified Player Identity)

## Three core problems for game studios
1. **Growth** (user acquisition + engagement)
2. **Attribution** (understanding users across fragmented platforms)
3. **Monetisation** (payments, economies, and long-term LTV)

## Market context
- Gaming is a ~$250B+ market with ~3.3B players.
- Growth is harder because: competition explosion, ATT/IDFA reducing ad effectiveness, fragmented player surfaces (Steam, Discord, socials).
- Monetisation is inefficient: app stores take ~30% fees; stablecoin payments cost ~1–1.5%. The economics will pull games to web3.
- Player identity is fragmented across platforms.

Opportunity pools: ads & attribution ($60–70B), payments ($20–25B in fees), in-game monetisation (~$150B annually).

## Core products

1. **Immutable zkEVM ("Immutable Chain")** — Ethereum L2 for games. NFTs, onchain economies, gas-free transactions. Solves monetisation limits & fragmented asset liquidity.
2. **Immutable Play** — Steam-like discovery + quests + rewards. Uses IMX incentives. Solves cold-start ("empty restaurant"), weak early engagement, community growth.
3. **Immutable Audience** (B2B CDP) — Audience CDP, Game Page, Engage, Amplify, AI Audience Copilot. Unified profiles, cross-channel attribution, predictive insights. Solves: launches that fail from poor audience, cold wishlists, broken attribution post-ATT.
4. **Immutable Passport** — wallet + identity layer. Email/social login abstracts crypto complexity. One identity across games; feeds Audience.
5. **Unified Audience Profile (UAP)** — gaming-native identity + attribution aggregating onchain activity, games, and social (Discord, X, Reddit). Single view of each player across games.

## System-level advantage
Immutable is vertically integrated:
- Growth → Audience
- Identity → Passport + UPI
- Monetisation → Chain
- Distribution → Play

Creates: unified data layer across all games, cross-game network effects, shared liquidity, better attribution & targeting. **Core insight: games don't need point solutions — they need a system.**

## Customers
- Game studios (primary buyer for Audience + infrastructure)
- Players (users of Play + Passport)
- IMX investors (token ecosystem participants)

## Key concepts
- **CDP** (Customer Data Platform): collects, unifies, and activates user data into a single profile.
- **UPI** (Unified Player Identity): persistent identity across games, wallets, and platforms enabling attribution, personalisation, and network effects.
