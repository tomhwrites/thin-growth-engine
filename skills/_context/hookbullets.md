# Hookbullets Form

This form is a compressed proof stack, not a mini-thread and not a slogan plus commentary.

## Structure

- Exactly 4 non-empty lines.
- Line 1 is the hook.
- Lines 2, 3, and 4 are bullet lines starting with `•`.
- No closer. No 5th line.

## Hook rules

- Lead with the takeaway, not a generic setup.
- Keep it short, claim-led, and concrete.
- Do not use the hook as a vague slogan the bullets then have to rescue.

## Bullet rules

- One proof point per bullet.
- Target 4-9 words per bullet. Hard max: 10 words.
- Start with the metric, partner, product, or named proof when natural.
- Do not turn bullets into full mini-sentences unless the fact demands it.
- Do not repeat the same subject phrase in all 3 bullets if it can be implied.
- Avoid packing two unrelated facts into one bullet.
- If a fact cannot fit cleanly inside the bullet length limit, choose a different fact instead of forcing it in.
- If a candidate fact would require a forbidden term from tweet-voice, choose a different fact instead of surfacing the forbidden term.

## Composition

- Spread the 3 bullets across different kinds of proof when possible:
  - scale / volume
  - behavior / engagement / retention
  - named partner / product / operator proof
- If only 2 strong metrics exist, the third bullet can be a named concrete proof point, not a slogan.

## Common failures

- no closer that moralizes the bullets
- no sweeping inevitability line
- no orphaned time qualifier line
- no balanced contrast constructions
- no bloated bullets that spend all the available characters
