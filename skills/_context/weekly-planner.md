# Weekly planner context

This workflow is for Immutable's co-founder account, but it is not a free-form brainstorm. It is an editorial planning system for a 15-tweet week.

## Weekly planner principles
- Plan for coverage across the week, not just single-tweet quality.
- Prefer distinct, non-overlapping narratives.
- Default to the established 15-slot BAU archetype mix unless the weekly context contains a genuinely new development.
- New developments should earn multiple slots only when they are concrete and newsworthy.

## Quality bar
- Avoid hypey or non-falsifiable framing in planning outputs.
- Do not smuggle in tweet copy or slogan lines during synthesis or planning.
- Weekly outputs should set up later drafting for evidence-backed tweets, especially for `hookbullets` archetypes where weak closers are a common failure mode.

## Drafting reminder for downstream weekly stages
- In `hookbullets`, the closer is optional.
- Prefer `hook + 3 concise bullets` over forcing a vague payoff line.
- If a closer is present, it must add a concrete implication, proof point, or operator takeaway.
- Reject sweeping payoff lines that merely sound bullish without adding evidence.
